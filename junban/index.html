くらし案内ドットコム › ご家族を見送ったあとにやること、9つの順番

ご家族を見送ったあとにやることは、9つ。順番だけ先に持って帰ってください。

2026年 最新版執筆・監修 くらし案内ドットコム事務局

ご家族を見送ったあと、半年〜1年でやることは決まっています。葬儀のあと → 手続き → 片付け → 相続 → 仏壇 → お墓 → 空き家 → 解体か売却 → 税の申告。順番を間違えると、払わなくてよかった費用を先に払ったり、戻せない締切を過ぎたりします。各工程の期限と根拠の条文を1画面にしました。

  1. 亡くなってから7日

    葬儀と死亡届

    死亡届は死亡を知った日から7日以内に市区町村へ（戸籍法86条）。葬儀社が代行することが多い。火葬許可証はこの届出で出る。

    死亡届 7日以内
  2. 〜14日、〜3か月

    亡くなった後の手続き

    国民年金は14日以内、厚生年金は10日以内に死亡の届出（年金事務所）。国民健康保険は14日以内に資格喪失の届出。相続放棄をするなら、相続を知った日から3か月以内に家庭裁判所へ（民法915条）。

    年金 10〜14日健康保険 14日相続放棄 3か月
    「亡くなった後の手続き」へ →
  3. 四十九日のあと

    片付けと遺品整理

    片付けの前に、家財そのままで査定と見積を取る。業者に頼むなら、3LDK以上の一軒家で50万〜100万円以上が目安（日本郵便の相場表）。家財ごと買い取る会社を選べば、片付け費用が0円になることもある。

    査定が先50万〜100万円
    「片付けと掃除」へ →
  4. 4か月・10か月・3年

    相続の手続きと期限

    亡くなった人の所得税の申告（準確定申告）は4か月以内（所得税法125条）。相続税の申告は10か月以内（相続税法27条）。相続登記は、相続で不動産を取得したと知った日から3年以内（不動産登記法76条の2）。話し合いが長引くなら相続人申告登記で義務だけ先に果たせる。

    準確定申告 4か月相続税 10か月相続登記 3年
    「相続と手続き」へ →
  5. 片付けと並行

    仏壇と位牌

    仏壇を処分するなら、閉眼供養（魂抜き）はお寺に頼む。処分そのものは自治体の粗大ごみか、片付けの業者に。新居に移すなら、移す前に相談する。

    閉眼供養はお寺
    「仏壇と位牌」へ →
  6. 納骨先が決まってから

    墓じまいと供養

    改葬許可は、今お墓がある市区町村が出す（墓地、埋葬等に関する法律5条）。最初に決めるのは新しい納骨先。費用は撤去・手続きとお寺・納骨先の3つに分かれ、総額の目安は35万〜150万円。

    改葬許可は今お墓がある市区町村35万〜150万円
    「墓じまいと供養」へ →
  7. 売るか壊すか決めるまで

    実家と空き家

    固定資産税は毎年1月1日の状況で決まる。空き家のまま放置して管理不全空家等の勧告を受けると、家が建っていても住宅用地の特例が外れる。売る・貸す・壊すの3つを手取りで比べてから動く。

    1月1日が基準勧告で特例が外れる
    「実家と空き家」へ →
  8. 出口を決めてから

    解体と工事、または売却

    木造30坪の解体は90万〜200万円が事業者の公表相場。補助金は交付決定の前に契約・着工すると出ない。壊したら1か月以内に建物滅失登記（不動産登記法57条）。買主が壊す条件で現状のまま売る形もある。

    90万〜200万円滅失登記 1か月
    「解体と工事」へ →
  9. 売った翌年の2〜3月

    税の申告

    実家を売った利益は、翌年の確定申告で申告する。取得費が分からない家は売った金額の5%が取得費。空き家の3,000万円特別控除は、相続開始から3年を経過する日の属する年の12月31日までの売却が条件（制度は2027年12月31日まで）。

    確定申告3,000万円控除は3年
    「相続と手続き」へ →
