家と土地の困りごと。売る・貸す・壊すの比べ方から、解体の相場、固定資産税まで

2026年 最新版執筆・監修 くらし案内ドットコム事務局

結論

家と土地の困りごとは、順番を決めると迷いません。実家や空き家は「家財そのままで査定と見積を取る → 買取・仲介・解体して土地で売るの3つを手取りで比べる → 必要な分だけ片付け・解体する → 相続登記 → 引き渡し」の順。解体は木造30坪で90万〜200万円が事業者の公表相場で、補助金は交付決定の前に契約・着工すると出ません。固定資産税は毎年1月1日の状況で決まり、空き家のまま管理不全空家等の勧告を受けると住宅用地の特例が外れます。

「家をどうするか」は、片付けや修繕より先に出口を決める話です。

  • 売る・貸す・壊すを手取りで比べる。家財が残ったままでも査定は取れます
  • 解体は木造30坪で90万〜200万円（事業者の公表相場）。着工7日前までの届出、取り壊しから1か月以内の滅失登記が法律で決まっています
  • 固定資産税は毎年1月1日の状況で課税。年内に更地にすると翌年度は住宅用地の特例が使えません

リフォーム・雨漏り・害虫・庭・水回りの各項目は、順に記事を公開していきます。

実家と空き家の記事（10本）

  • 相続人申告登記とは。話し合いが終わらなくても3年の義務を果たせる仕組みと、できないこと

    相続人申告登記は、遺産分割がまとまらなくても「自分が登記名義人の相続人である」ことを法務局に申し出るだけで、相続登記の3年の申請義務を果たせる仕組みです。登録免許税はかかりません。ただし名義は移らないので、実家を売るには

  • 相続登記をしないとどうなる？ 2024年4月からの義務化・3年の期限・10万円以下の過料

    相続登記は2024年4月1日から義務です。相続で不動産を取得したと知った日から3年以内に登記しないと10万円以下の過料の対象。2024年3月以前に相続を知っていた分も2027年3月31日が期限。登記がまだでも実家の査定や

  • 相続した実家を売ると税金が0円になることも。空き家の3,000万円特別控除の条件（2027年12月31日まで）

    相続した実家を売ったときの利益から最大3,000万円を差し引ける「被相続人の居住用財産（空き家）の特例」。昭和56年5月31日以前の建築、売却代金1億円以下、相続から3年後の年の12月31日までの売却、2027年12月3

  • 家財が残ったままの実家は売れる？ 片付けてから仲介で売る場合と、そのまま買取の手取り比較

    家財が残ったままでも実家は売れます。家財ごと買い取る会社に頼めば片付け費用はかかりません。遺品整理の費用相場（一軒家で50万〜100万円以上）と、片付けてから仲介で売る場合との手取りの違いを、費用・期間・手間で比較します

  • 実家を解体すると固定資産税はどうなる？ 更地の税、1月1日の判定日、解体してから売る損得

    家を解体して更地にすると、住宅用地の特例（課税標準6分の1）が外れます。ただし更地の課税標準は評価額の70%が上限になるため、土地の固定資産税は最大でも約4.2倍です。判定日は毎年1月1日。年内に壊すと直後の1月1日から

  • 実家じまいとは。費用の全体像（片付け・解体・登記・税）と、損しない順番

    実家じまいは、相続した実家を「売る・貸す・壊す」のどれかで手放すまでの一連の手続きです。費用は片付け（3LDK以上の一軒家で50万〜100万円以上）、解体（木造30坪で90万〜200万円・必要な場合だけ）、相続登記の登録

  • 実家じまいは何から手をつける？ 損しない順番と、やってはいけない3つの順番

    実家じまいは「査定 → 売り方を決める → 必要な分だけ片付け・解体 → 相続登記 → 引き渡し」の順です。先に片付けると家財ごと買い取る会社を選べなくなり、片付け費用が無駄になることがあります。解体を先にすると固定資産

  • 実家の解体費用はいくら？ 木造30坪の相場、付帯工事、自治体の補助金（着工前の申請が条件）

    木造の解体は坪3万〜7万円、30坪で90万〜200万円が事業者の公表相場。残置物や塀・庭木の撤去は別料金です。老朽空き家の解体に工事費の3分の1〜5分の4（上限20万〜150万円程度）を補助する自治体があり、着工前の交付

  • 実家を売ったときの税金の計算。取得費が分からない家の5%、3,000万円の特例、長期譲渡の20.315%

    実家を売って出た利益には所得税と住民税がかかります。親が何十年も前に建てた家は取得費が分からないことが多く、その場合は売った金額の5%を取得費とみなせます。利益から空き家の3,000万円特別控除を引き、残りに長期譲渡の税

  • 空き家の固定資産税が最大6倍になる仕組み。「特定空家」「管理不全空家」の勧告で何が起きるか

    住宅が建つ土地は固定資産税の課税標準が最大6分の1に軽減されています。空き家が「特定空家等」または「管理不全空家等」として勧告を受け、1月1日までに直さないとこの特例が外れます。ただし更地の課税標準には価格の70%という

  • 建物滅失登記は取り壊しから1か月以内。怠ると10万円以下の過料

    建物を壊しても、登記の記録は自動では消えません。不動産登記法57条は、滅失の日から1か月以内の申請を義務づけ、164条1項は正当な理由なく怠った場合の10万円以下の過料を定めています。誰が・いつまでに・どこへ申請するのか

  • 相続登記が終わっていなくても、実家は解体できる。名義が親のままでも滅失登記は相続人が出せる

    「名義が親のままだから、まず相続登記をしないと壊せない」と思われがちですが、そうではありません。不動産登記法30条は、相続があったときは相続人が表示に関する登記を申請できると定めています。建物滅失登記は表示に関する登記な

  • 解体の届出は誰が出す？ 80㎡以上は着工7日前まで、義務者は発注者

    床面積80㎡以上の解体は、建設リサイクル法の対象です。工事着手の7日前までに、業者ではなく発注者（依頼した本人）の名前で都道府県知事へ届け出ます。実務では業者が代行しますが、届け出なければ20万円以下の罰金を受けるのは発

  • 解体の見積、「一式」では比べられない。内訳5項目と金額が上下する条件

    解体の見積は本体工事・養生・付帯工事・廃棄物処理・諸経費に分かれます。「一式いくら」では、どこが高いのかを比べられません。木造30坪は90万〜200万円が目安。道路の幅・隣家との距離・地中とアスベストで数倍の差がつく理由

  • 解体前に施主がやること。チェックリストと、やってはいけないこと（水道の停止日を先に決めない）

    解体の前に施主がやることは決まっています。家財の仕分け、家電4品目の処分の手配、電気・ガス・電話・ネットの解約、水道は業者と相談、補助金の交付決定、届出の確認、近隣説明の分担、貴重品と書類の持ち出し。逆にやってはいけない

  • 解体の近所あいさつは義務？ 法律が求めているのは「行政への届出」で、近隣説明は自治体の要綱

    近隣へのあいさつを法律が義務づけている、という決まりはありません。騒音規制法と振動規制法が求めているのは指定地域内の工事についての市区町村への届出で、作業開始の7日前まで、届け出るのは施工業者です。近隣への説明が必要にな

  • 家の解体は何日かかる？ 工事は8日〜2週間、その前に調査と届出の時間が要る

    木造30坪の解体工事そのものは8日から2週間ほどです。ただし着工までに、石綿（アスベスト）の事前調査、床面積80㎡以上なら着工7日前までの届出、補助金を使うなら交付決定を待つ時間が別にかかります。工事の前後を含めた全体の

  • 解体するとき、エアコンや冷蔵庫はどうする？ 家電4品目は「残置物」で、処理責任は所有者にある

    エアコン・テレビ・冷蔵庫・洗濯機の4品目は、家電リサイクル法の対象です。経済産業省は、解体現場に残された家電4品目は「残置物」で、処理責任は所有者にあると示しています。解体費に含まれていると思い込むと、着工の直前に別料金

  • 解体前の電気・ガス・水道はいつ止める？ 水道だけは止める日を業者と相談する

    電気・ガス・電話・インターネットは契約している会社へ連絡すれば済みます。行政の届出ではありません。ところが水道だけは扱いが違い、解体工事では散水に水を使うため、止める日を先に業者と相談する必要があります。給水管の切り離し

  • 解体前のアスベスト事前調査。2023年10月から有資格者が必要です

    2023年10月1日に着工する工事から、解体前の石綿（アスベスト）事前調査は建築物石綿含有建材調査者などの有資格者が行うことになりました。調査は原則として建物の規模を問わず必要で、解体部分が80㎡以上なら元請が労働基準監

  • 家を壊す前のお祓いは必要か。法律上の義務はない、初穂料の公表例、やる場合の順番

    家を解体する前のお祓い（解体清祓・解体のおはらい）は、法律上の義務ではありません。解体に関わる法律のどこにも定めはなく、やるかどうかは施主の判断です。「相場」という共通の数字もなく、神社が公表している例では解体祭・改築祭

  • 家の解体の流れ。相談から滅失登記まで、誰が・いつ・何をやるかの全工程

    家の解体は、業者探し・見積・契約・届出・ライフラインの停止・工事・滅失登記の順に進みます。工事そのものは木造30坪で8日〜2週間（業者サイトの目安）ですが、その前後に法律で決まった手続きがあります。着工の7日前までの届出

  • 空き家の解体補助金、5市の実例。交付決定前の契約・着工は対象外
