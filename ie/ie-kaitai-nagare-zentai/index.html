家の解体の流れ。相談から滅失登記まで、誰が・いつ・何をやるかの全工程

2026年 最新版執筆・監修 くらし案内ドットコム事務局

結論

家の解体は、①業者を探して明細つきの見積を最大3社で比べる ②契約（解体費と再資源化等の費用を分けて明記）③石綿の事前調査（2023年10月から有資格者）④建設リサイクル法の届出（床面積80㎡以上・着工の7日前まで・発注者名義）⑤電気・ガス・電話・ネットの解約（水道は止める日を業者と相談してから）⑥近隣への説明 ⑦工事（木造30坪で8日〜2週間・業者サイトの目安）⑧建物滅失登記（取り壊しから1か月以内・怠ると10万円以下の過料）の順に進みます。補助金を使う場合は、②より前に申請して交付決定を受けておく必要があります。完了を希望する日の約2か月前から動き始めるのが目安です。

「家を壊すのに、何をどの順番でやればいいのか」。解体の相談で最初に出る質問です。工事そのものは業者がやりますが、その前後にあなたの名前で出す書類と、あなたが決める段取りがあります。全工程を誰が・いつ・何をで並べます。

① 業者探し・見積（約2か月前から）

常総市は空き家の解体について「工事の完了を希望する約2ヶ月前から、開始します」と案内しています。時間がかかるのは工事ではなく、業者探し・契約・家財の処分・届出の方だからです。

見積は「一式」ではなく、本体工事・養生・付帯工事・廃棄物処分・諸経費の5つに分かれた明細で、最大3社を同じ条件で並べます。家財（残置物）がどの部屋にどれくらい残っているかは、この段階で伝えておくと後から足されません。

ここまでの目安で、いちど見積を取ってみますか。

解体の見積を無料で手配する（最大3社）

紹介は無料・入力1分・断っても費用はかかりません

② 契約（補助金を使うなら交付決定のあと）

環境省は、対象建設工事の請負契約の締結に当たって「解体工事に要する費用や再資源化等に要する費用を明記することを義務付ける」と説明しています（建設リサイクル法13条と主務省令）。契約書で分けるものを、見積で分けられない理由はありません。

補助金を使う場合は、順番が命です。名古屋市は「補助金の交付決定前に着手した工事は対象外」、新潟市も「補助金交付決定前に表に掲げる事業に着手した場合は、対象外」と明記しており、調べた自治体はいずれも同じ扱いでした。「自治体に確認 → 見積 → 申請 → 交付決定 → 契約」の順に組みます。

③④ 着工前の2つの手続き

石綿（アスベスト）の事前調査は、2023年10月1日に着工する工事から、有資格者が行います。厚生労働省は、原則として工事の規模や種類にかかわらず必要としています。解体部分の延べ床面積80㎡以上なら、元請が調査結果を労働基準監督署と都道府県等へ電子で報告します。

建設リサイクル法の届出は、床面積80㎡以上の解体で、着工の7日前までに、発注者（あなた）の名前で都道府県知事へ出します。実務では業者が委任状で代行しますが、義務者はあなたです。「届出は誰が、いつ出しますか。控えはもらえますか」と聞いておいてください。なお、床面積10㎡を超える建物の除却は建築基準法15条の届出も要り、多くの自治体で建設リサイクル法の届出と一緒に案内されています（益田市）。

⑤ ライフラインは「水道だけ別」

電気・ガス・電話・インターネットは、契約している会社に連絡して止めます。行政の届出ではありません。

水道は、止める日を先に決めないでください。解体では粉じんを抑えるために散水することがあり、益田市は「水道の停止日については、事前に解体業者とご相談ください」と案内しています。給水管の切り離しやメーターの返納は指定給水装置工事事業者しか施工できず、申請人は所有者です（いわき市水道局）。下水道は使用廃止の届出を出さないと、使っていなくても使用料を請求されることがあります（田上町）。

⑥ 近隣への説明

近隣へのあいさつを法律が義務づけている規定はありません。法律が求めているのは、指定地域内で特定建設作業（大型のバックホウやブレーカーを使う作業など）を伴う場合の市区町村への届出です（騒音規制法14条1項・振動規制法14条1項）。義務者は施工業者、期限は作業開始の7日前まで。小さな木造住宅で該当しないこともあります。近隣説明が必要になるのは自治体の要綱で、江東区は工事開始の7日前まで、世田谷区は3日前まで。誰が回るかは業者と分担を決めておきます。

⑦ 工事

足場と養生 → 内装と残置物の撤去 → 建物本体の解体 → 基礎と外構の撤去 → 整地。木造30坪で8日〜2週間が目安（業者サイトの公開値・現場条件で大きく変わります）。家電4品目（エアコン・テレビ・冷蔵庫・洗濯機）は残置物で、処理責任は所有者にあります（経済産業省）。建物と一緒には壊せません。

工事が終わって更地になっても、建物の登記は壊しただけでは消えません。不動産登記法57条により、取り壊しの日から1か月以内に建物滅失登記を申請します。怠ると10万円以下の過料（164条1項）。名義が亡くなった親のままでも、相続人が申請できます（30条）。

時期を決めるときに、もう1つ

固定資産税は毎年1月1日の状況で課税されます（総務省）。年内に更地にすると、翌年度は土地の住宅用地の特例が使えません。急ぐ理由がなければ、年明けに回すという選び方があります。

まとめ

  • 8段階。工事は⑦だけで、前後にあなたの名前で出す書類がある
  • 期限は3つ。着工7日前の届出（吹付け石綿があれば別の届出が14日前）、取り壊しから1か月以内の滅失登記、補助金は交付決定の前に契約しない
  • 完了希望の約2か月前から動く。時間がかかるのは工事ではなく手前

解体案内所は施工しません。解体する家のある地域で対応できる登録業者を手配し、明細つきの見積を最大3社まで並べます。届出を誰が出すか、近隣説明を誰が回るかは、見積の段階で業者に確認してください。業者からあなたへ営業電話をかけることはなく、連絡は最大3社の見積だけです。

見積が必要になったら、解体案内所で地域の会社を最大3社まで無料で手配できます。

よくある質問

解体はどれくらいの期間で終わりますか

工事そのものは木造30坪で8日〜2週間が目安（業者サイトの公開値）。業者探しから更地になるまでは、補助金を使わない場合でもひと月では収まりにくく、補助金を使うなら自治体の審査期間が加わります。完了を希望する日の約2か月前から動き始めてください。

届出は自分でやるのですか

建設リサイクル法の届出は発注者（あなた）が義務者ですが、実務では業者が委任状で代行します。控えをもらってください。騒音・振動規制法の届出は施工業者が出します。

壊したあとに何か手続きは要りますか

建物滅失登記が要ります。取り壊しの日から1か月以内で、怠ると10万円以下の過料の定めがあります。自分でも申請できますし、土地家屋調査士に頼むこともできます。
