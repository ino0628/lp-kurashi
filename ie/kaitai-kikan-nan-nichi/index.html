家の解体は何日かかる？ 工事は8日〜2週間、その前に調査と届出の時間が要る

2026年 最新版執筆・監修 くらし案内ドットコム事務局

結論

木造30坪の家なら、解体工事そのものは8日から2週間ほどが目安です。ただし工事に入る前に、石綿（アスベスト）の事前調査、床面積80㎡以上の解体なら着工の7日前までに済ませる建設リサイクル法の届出、補助金を使う場合は交付決定を待つ期間が別に必要です。補助金を使わない場合で、業者を決めてから更地になるまでおおむね1か月前後、補助金を使う場合は自治体の審査期間が加わります。工事が終わったあとは、取り壊しの日から1か月以内に建物滅失登記を行います。

「解体って、どれくらいで終わるんですか」。日程を決めたい方から、必ず伺う質問です。工事そのものは、木造30坪で8日から2週間ほど。ただし、これは重機が入ってからの日数です。実際には、業者を決めてから工事に入るまでに別の時間がかかります。

重機が入って手作業が少ない現場の目安。業者サイトの公開値で、現場条件で大きく変わる。

木造30坪の解体で、解体業者や一括見積サイトが示している目安はおおむね次のとおりです。18坪程度で5日前後、28〜35坪で8〜10日程度、一般的な一軒家で約2週間。85坪を超える規模になると14日から45日という幅が示されています。いずれも業者サイトの公開値で、一次資料（官公庁）の数字ではありません。現場条件で大きく変わります。

工事の中身は、足場と養生 → 内装と残置物の撤去 → 建物本体の解体 → 基礎の撤去 → 整地、という順に進みます。手作業で外す部分が多い現場、隣家との距離が近くて重機を使えない現場では、日数が延びます。

着工までに要る時間

工事の前に、必ず入る手続きが2つあります。

石綿（アスベスト）の事前調査は、2023年10月1日に着工する工事から、有資格者による調査が必要になりました。厚生労働省は、事前調査そのものは原則として規模の大小にかかわらず、解体・改修に係る部分の全ての材料について必要だとしています。さらに、解体部分の延べ床面積が80㎡以上の工事は、調査結果の電子報告が義務です。調査で石綿を含む建材が見つかると、除去の計画と作業が加わるので、日数も費用も大きく動きます。

建設リサイクル法の届出は、床面積80㎡以上の解体で必要です。環境省は対象工事の規模基準を「建築物の解体工事では床面積80m2以上」と示しています。届出は着工の7日前までに、発注者（施主）の名前で都道府県知事へ提出します。実務では業者が委任状で代行しますが、義務を負っているのは施主です。この7日間は縮められません。吹付け石綿など飛散のおそれがある建材が見つかった場合は、作業の14日前までに別の届出（特定粉じん排出等作業届・これも発注者の名前で出します）が要り、7日前ではなく14日前が締切になります（益田市）。

補助金を使う場合は、ここに自治体の審査期間が加わります。名古屋市は補助金について「補助金の交付決定前に着手した工事は対象外となります」と明記しています。新潟市も「補助金交付決定前に表に掲げる事業に着手した場合は、対象外」としており、調べた5市すべてで同じ扱いです。つまり順番は「申請 → 交付決定 → 契約 → 着工」で、交付決定を待つ間は動けません。

業者を決めてから更地になるまで、おおむね1か月前後。業者探しから数えると、常総市は「工事の完了を希望する約2ヶ月前から、開始します」と案内しています。補助金を使う場合は、これに自治体の審査期間が乗ります。

工事が終わって更地になっても、手続きが1つ残ります。建物滅失登記です。取り壊しの日から1か月以内に行う必要があり、怠ると10万円以下の過料の定めがあります（不動産登記法57条・164条1項）。自分で申請することもできますし、土地家屋調査士に依頼することもできます。

時期を決めるときに、もう1つ

日程には、税金の区切りが関係します。固定資産税の賦課期日は毎年1月1日で、この日の状況で課税されます（総務省）。年内に解体して更地にすると、翌年度は土地の住宅用地の特例が使えません。逆に、1月2日以降に解体すれば、その年度は特例が残るのが原則です。ただし、管理不全空家等や特定空家等として勧告を受けている土地は、建物があっても特例が外れています（空家等対策の推進に関する特別措置法）。実際の税額と特例の有無は、家のある市区町村の資産税の窓口で確認してください。当社は税額の計算や税務の相談は行いません。

急ぐ理由がないなら、年末の着工は避けて年明けに回すという選び方があります。逆に、売却の予定が決まっていて早く引き渡したい場合は、税額より日程を優先することもあります。どちらが得かは金額次第なので、見積が出た段階で、税額の差と合わせて考えてください。

まとめ

  • 工事そのものは木造30坪で8日〜2週間（業者サイトの目安）。時間がかかるのは手前の手続き
  • 着工前に石綿の事前調査と、80㎡以上なら着工7日前までの届出（吹付け石綿があれば14日前）
  • 補助金は交付決定の前に契約・着工しない。審査期間は自治体に聞く
  • 終わったら1か月以内に建物滅失登記。時期は1月1日の固定資産税も見て決める

よくある質問

急いでいます。最短でどれくらいですか

補助金を使わず、石綿の調査で除去が必要にならなければ、業者を決めてから更地になるまで1か月前後が目安です。ここから縮めにくいのは、着工7日前までの届出と、調査の日程です。工事そのものを速める余地は多くありません。

補助金を使うとどれくらい延びますか

自治体の審査期間の分だけ延びます。共通しているのは、交付決定より前に契約・着工した工事は対象外になることです。つまり「申請 → 交付決定 → 契約 → 着工」の順番を守る必要があり、この待ち時間が全体の日数を決めます。窓口で今年度の受付状況と審査の目安を先に聞いてください。

雨や雪で延びますか

延びることがあります。散水しながら解体するので雨そのものは止める理由になりにくい一方、強風はシートや高所の作業に影響します。近隣への配慮で作業を止める日もあります。日程に数日の余裕を見ておくと安心です。
